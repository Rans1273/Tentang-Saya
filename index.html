Tentang Saya

Halo! Nama saya Asran, S.T., lulusan Sarjana Teknik Komputer dari Universitas Borneo Tarakan (UBT). Saya memiliki minat mendalam serta pengalaman praktis dalam merancang integrasi perangkat keras IoT, pengembangan sistem web menggunakan kerangka kerja Laravel & PHP, serta aplikasi mobile berbasis Flutter.

Melalui latar belakang akademis dan pengalaman proyek riset seperti skripsi sistem perpustakaan pintar berbasis IoT & Machine Learning, saya siap mendedikasikan keahlian di bidang teknologi untuk menciptakan solusi inovatif.
