# Portofolio Pribadi - Asran

Portofolio web pribadi yang dirancang menggunakan:
- **HTML5 & CSS3**
- **Bootstrap 5**
- **JavaScript (Vanilla JS modular)**

## Fitur
- Navigasi antar halaman (Beranda, Tentang, Pengalaman, Proyek, Kontak).
- Slide pertama dengan foto profil transparan.
- Halaman Pengalaman mencakup Kerja Praktek STO Tarakan, Pengembangan Website SDA Bulungan, Pelatihan Komunikasi Digital SMP Tanjung Palas Utara, dan Hima Teknik Komputer UBT.
- Card Template Proyek interaktif lengkap dengan tag teknologi (`#dart`, `#flutter`, dll).
- Halaman Kontak dengan tautan sosial media (LinkedIn, Instagram, GitHub) serta form pesan interaktif.
